## 1. 价值投资 (Value Investing)

### 核心思想

以低于内在价值的价格买入优质资产，耐心等待市场定价回归。源自格雷厄姆，由巴菲特发扬光大。

### 关键指标

| 指标 | 公式 | 判断标准 |
|:-----|:-----|:---------|
| **PE (市盈率)** | 股价 / 每股收益 | < 15 低估，15-25 合理，> 25 高估 |
| **PB (市净率)** | 股价 / 每股净资产 | < 1.5 安全边际充足 |
| **ROE (净资产收益率)** | 净利润 / 净资产 | > 15% 持续 3 年以上为优 |
| **股息率** | 每股分红 / 股价 | > 3% 提供安全垫 |
| **自由现金流收益率** | 自由现金流 / 市值 | > 8% 被低估信号 |
| **负债率** | 总负债 / 总资产 | < 50% 财务安全 |

### 实操步骤

```
1. 筛选：PE < 15 且 ROE > 15% 且 负债率 < 50%
2. 排除：连续 3 年营收下滑、管理层减持、商誉占比过高
3. 估值：DCF 模型估算内在价值，要求 30%+ 安全边际
4. 分批买入：分 3 次建仓（首次 40%，回调 10% 加 30%，再跌 10% 加 30%）
5. 持有条件：基本面未恶化就持有，不理会短期波动
6. 卖出信号：PE > 25 或基本面恶化或发现更好的标的
```

### 格雷厄姆数值

格雷厄姆提出过一个简易估值公式：

```
内在价值 = EPS × (8.5 + 2g) × 4.4 / Y

其中：
  EPS = 过去 12 个月每股收益
  g   = 未来 7-10 年预期增长率 (%)
  Y   = 当前 AAA 级公司债收益率 (%)
  4.4 = 1962 年 AAA 债券收益率（基准值）
```

### 经典案例

- **巴菲特买苹果**：2016 年 PE 约 12，ROE > 35%，自由现金流充沛，持有至今收益 5x+
- **A股招商银行**：常年 PE < 8，PB < 1，ROE > 15%，股息率 > 4%

## 2. 股息复利 (Dividend Compounding)

### 核心思想

买入稳定分红的优质公司，将分红自动再买入（DRIP），利用复利效应让资产长期增长。「时间的复利」是最强大的力量。

### 关键指标

| 指标 | 说明 | 筛选标准 |
|:-----|:-----|:---------|
| **股息率** | 年分红 / 股价 | > 3%（A 股 > 4%） |
| **分红连续性** | 连续分红年数 | > 5 年，最好 10 年+ |
| **分红增长率** | 年均分红增速 | > 5% |
| **派息比率** | 分红 / 净利润 | 40%-70%（太低不慷慨，太高不可持续） |
| **盈利稳定性** | 净利润波动 | 近 5 年无亏损年份 |

### 股息复利公式

```
第 N 年总资产 = 本金 × (1 + 股息率 × 再投资比例)^N + 股价增值部分

简化估算（全部再投资）：
  10 万本金，年化股息率 5%，全部再投资
  10 年后 ≈ 10万 × 1.05^10 ≈ 16.3 万（仅分红复利，不含股价涨跌）
  20 年后 ≈ 10万 × 1.05^20 ≈ 26.5 万
  30 年后 ≈ 10万 × 1.05^30 ≈ 43.2 万
```

### 实操步骤

```
1. 筛选「股息贵族」：连续 10 年+ 增加分红的公司
2. 检查质量：ROE > 12%，负债率 < 60%，经营现金流 > 净利润
3. 分散持仓：5-10 只不同行业的高股息股
4. 开启自动再投资：有条件就用 DRIP（分红自动买股）
5. 年度再平衡：每年检查一次，剔除分红减少的标的
```

### A 股高股息方向

- **银行股**：工商银行、建设银行（股息率 5-6%）
- **煤炭能源**：中国神华、陕西煤业（股息率 6-8%）
- **高速公路**：宁沪高速、山东高速（股息率 5-7%）
- **公用事业**：长江电力（股息率 3-4%，分红极稳定）

## 3. 指数定投 (Index DCA)

### 核心思想

定期定额买入宽基指数基金，不择时、不选股，用纪律战胜人性弱点。长期来看，80% 的主动基金经理跑不赢指数。

### 定投收益公式

```
总份额 = Σ(每月投入金额 / 当月净值)
总成本   = 月投入 × 月数
平均成本 = 总成本 / 总份额

盈利条件：当前净值 > 平均成本
```

### 三大经典指数组合（Boglehead 三基金）

| 资产类别 | 配比 | A 股对应 | 美股对应 |
|:---------|:-----|:---------|:---------|
| 国内股票 | 60% | 沪深 300 ETF (510300) | VTI (全市场) |
| 国际股票 | 20% | 标普 500 ETF (513500) | VXUS (国际) |
| 国内债券 | 20% | 十年国债 ETF (511260) | BND (全债) |

### 进阶：估值定投

普通定投是傻买，估值定投是「便宜多买、贵了少买」：

```
PE 百分位 < 30%：投入 2 倍基础金额（低估，多买）
PE 百分位 30-70%：投入 1 倍基础金额（正常）
PE 百分位 > 70%：投入 0.5 倍基础金额（高估，少买）
PE 百分位 > 90%：暂停定投，持有不动（极度高估）
```

### A 股定投实操

```
1. 选择标的：沪深 300 ETF (510300) 或 中证 500 ETF (510500)
2. 设定周期：每月发工资后第一天自动扣款
3. 金额：月收入的 10%-30%
4. 卖出条件：
   - 达到目标收益（如翻倍）可分批止盈
   - PE 百分位 > 80% 分批赎回
   - 绝不因短期下跌止损
5. 心态：至少坚持 3 年以上，穿越一个完整牛熊周期
```

### 历史回测参考

- 沪深 300 自 2005 年以来，任意定投 3 年正收益概率 > 70%
- 定投 5 年正收益概率 > 85%
- 定投 10 年正收益概率 > 95%

## 4. 动量趋势 (Momentum & Trend Following)

### 核心思想

"趋势是你的朋友"。买入近期表现强势的资产，持有到趋势结束。不预测方向，只跟随方向。这是量化对冲基金最经典的策略之一。

### 核心指标

**1. 相对动量 (Relative Momentum)**

```
动量得分 = (今日收盘价 / N日前收盘价 - 1) × 100%

N = 20（月度）、60（季度）、120（半年）

选股规则：计算所有候选股的 12 个月动量（剔除最近 1 个月），
         选排名前 10% 的股票等权持有，每月再平衡。
```

**2. 双动量 (Dual Momentum) —— GARY ANTONACCI 经典策略**

```
每月末检查：
  1. 计算股指（如沪深 300）过去 12 个月收益率
  2. 计算国债指数过去 12 个月收益率

规则：
  IF 股指收益 > 0 且 股指收益 > 债券收益：
      → 全仓股票指数
  ELIF 股指收益 < 0：
      → 全仓债券指数（绝对动量避跌）
  ELSE：
      → 全仓股票指数（相对动量选优）
```

**3. 均线趋势系统**

```
双均线交叉：
  金叉（短期均线上穿长期均线）→ 买入
  死叉（短期均线下穿长期均线）→ 卖出

推荐参数：MA20 / MA60（短线）或 MA50 / MA200（长线）

ATR 止损：
  止损价 = 买入价 - 2 × ATR(14)
  ATR(14) = 过去 14 日真实波幅的平均值
```

### 实操步骤

```
1. 选股池：沪深 300 成分股（流动性充足）
2. 每月末计算 12-1 动量（过去 12 个月收益，剔除最近 1 个月）
3. 选排名前 30 只，等权分配资金
4. 止损：单只亏损 > 10% 或跌破 MA60 则卖出换股
5. 每月再平衡一次，重新排名换仓
```

## 5. 均值回归 (Mean Reversion)

### 核心思想

"涨多了必跌，跌多了必涨"。价格偏离均值后倾向于回归。适合在市场恐慌时逆向买入，在狂热时逆向卖出。

### 核心指标

**1. RSI 超卖策略**

```
RSI(14) = 100 - 100 / (1 + RS)
RS = 14 日内平均涨幅 / 14 日内平均跌幅

买入信号：RSI(14) < 30（超卖）
卖出信号：RSI(14) > 70（超买）
```

**2. 布林带回归**

```
中轨 = MA(20)
上轨 = MA(20) + 2 × σ(20)
下轨 = MA(20) - 2 × σ(20)

买入信号：价格跌破下轨（2 个标准差之外，统计上仅 5% 概率）
卖出信号：价格回到中轨或触及上轨
```

**3. 配对交易 (Pairs Trading)**

```
1. 找两只高度相关的股票（如招行 vs 工行，相关性 > 0.8）
2. 计算价差 Z-Score：
   Z = (价差 - 价差均值) / 价差标准差
3. 交易规则：
   Z > 2.0  → 做空强势股，做多弱势股（价差过大，会回归）
   Z < -2.0 → 做多强势股，做空弱势股（价差过小，会扩大）
   |Z| < 0.5 → 平仓（价差回归正常）
```

### 实操步骤（RSI + 布林带组合）

```
1. 从沪深 300 中筛选基本面尚可的股票（排除 ST、退市风险）
2. 每日收盘后扫描：
   - RSI(14) < 30 且 收盘价 < 布林下轨 → 加入观察池
   - 连续 2 日满足上述条件 → 次日开盘买入
3. 仓位：单只不超过总资金 10%，总持仓不超过 50%
4. 止盈：RSI 回到 50 以上或价格触及 MA20
5. 止损：买入后跌 > 8% 认错出局
```

## 6. 多因子量化 (Factor Investing)

### 核心思想

不靠单一指标选股，而是把多个有效因子（价值、质量、动量、规模等）综合打分，系统化选股。这是学术界和业界验证最充分的策略体系。

### 六大经典因子

| 因子 | 代表指标 | 经济逻辑 | 长期超额收益 |
|:-----|:---------|:---------|:-------------|
| **价值** | PE、PB、股息率 | 低买高卖 | 年化 3-5% |
| **质量** | ROE、毛利率、现金流 | 优质公司持续创造价值 | 年化 2-4% |
| **动量** | 12-1 月收益率 | 趋势惯性 | 年化 3-6% |
| **小盘** | 市值 | 小公司成长空间大 | 年化 2-3% |
| **低波动** | 120 日波动率 | 低风险异象 | 年化 1-3% |
| **盈利** | SUE（标准化预期外盈利） | 盈利惊喜驱动 | 年化 2-4% |

### 多因子打分模型

```python
# 伪代码：多因子综合打分

def score_stock(stock):
    s = 0
    # 价值因子（权重 25%）
    s += 0.25 * rank(stock.pe)            # PE 越低分越高
    s += 0.25 * rank(stock.pb)            # PB 越低分越高
    
    # 质量因子（权重 25%）
    s += 0.25 * rank(stock.roe)            # ROE 越高越好
    s += 0.25 * rank(stock.fcff_yield)     # 自由现金流收益率
    
    # 动量因子（权重 25%）
    s += 0.25 * rank(stock.momentum_12m)   # 12 个月动量
    
    # 低波动因子（权重 25%）
    s -= 0.25 * rank(stock.volatility_120d) # 波动越低分越高
    
    return s

# 选股：综合得分前 50，等权或按得分加权持有，每月再平衡
```

### A 股因子有效性

```
A 股市场因子有效性排序（基于学术研究）：
  1. 价值因子    ⭐⭐⭐⭐⭐  最稳定，PE/PB 在 A 股非常有效
  2. 质量因子    ⭐⭐⭐⭐   ROE 高的公司长期跑赢
  3. 动量因子    ⭐⭐⭐    A 股动量周期较短（1-3 个月）
  4. 小盘因子    ⭐⭐⭐    注册制后小盘效应减弱但仍有效
  5. 低波动因子  ⭐⭐⭐    A 股高波动股长期跑输
```

### 实操步骤

```
1. 确定股票池：全 A 股，排除 ST、上市 < 1 年、日均成交额 < 5000 万
2. 每月末计算每个因子的排名得分
3. 综合打分，选前 50 只
4. 等权持有，每月末再平衡
5. 风控：单只持仓 < 5%，行业集中度 < 30%

工具推荐：
  - Tushare / AkShare（Python 数据源）
  - 聚宽 / 米筐（在线回测平台）
  - Backtrader / Zipline（本地回测框架）
```

## 🔧 风险管理（所有策略通用）

### 仓位管理

```
单只股票最大仓位：10%
单一行业最大仓位：25%
现金保留：至少 10%（永远不满仓）
总持仓：不超过总资金的 90%
```

### 止损纪律

| 策略类型 | 止损线 | 说明 |
|:---------|:-------|:-----|
| 价值投资 | 基本面恶化即卖 | 不设技术止损，以基本面为准 |
| 股息复利 | 分红减少或取消 | 分红是核心逻辑，分红断了就走 |
| 指数定投 | 不止损 | 越跌越买，不止损 |
| 动量趋势 | MA60 跌破或 ATR 止损 | 严格纪律，趋势破了就走 |
| 均值回归 | 8-10% 硬止损 | 认错要快 |
| 多因子量化 | 月度再平衡自动换仓 | 系统执行，不人为干预 |

### 散户铁律

```
1. 永远不用杠杆（融资融券、期权）
2. 永远不满仓（留 10%+ 现金）
3. 单只股票不超过 10%
4. 不懂的不碰（加密货币、衍生品、外汇）
5. 短期亏损不补仓（除非是定投策略）
6. 盈利不骄傲，亏损不恐慌
7. 投资的钱必须是 3 年内不用的闲钱
8. 记录每一笔交易，定期复盘
```
